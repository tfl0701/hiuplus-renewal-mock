한눈에

  • 첫 화면은 시안 그대로 써요. 오타 세 곳만 고쳤어요(이어폰 → 아이폰 등).
  • 뒤에 붙는 화면 30여 개를 시안 모양으로 이어 만들었어요. 검정 머리, 둥근 회색 카드, 계절 색 라벤더, 신청 단추에만 마젠타.
  • 고르는 순서와 금액표 줄 이름은 지금 사이트 그대로 둬서 기존 손님이 헤매지 않게 했어요.
  • 새로 넣은 건 세 가지예요. 24개월 동안 덜 내는 할인 방법 알려주기, 요금제마다 월 납부 금액 같이 보여주기, 접수 뒤에 할 일을 단추 하나로 보여주기.
  • 로그인이나 입력 없이 한 화면씩 넘겨 보는 «화면 순서대로 보기»를 넣었어요. 주문하기 17 · 회원가입 8 · 마이페이지 11 · 파트너스 9 · 둘러보기 23 · 직원 관리 10화면.
  • 2차 피드백을 반영했어요. 구매후기는 손님이 올리는 피드로 바꾸고 직원이 감출 수 있게 했고, 하유 가이드 글을 고치는 직원 관리 화면, 파트너스 안내 · 가입, 배송조회를 더했어요.
  • 3차에서 가입내역 받는 방법 · 신청내역 확인 링크를 넣고, 배송조회를 실제로 되는 방식(택배사 화면)으로 고쳤어요. 배너 5초 넘김, 휴대폰 + 인터넷 결합 공간, 색상 동그라미, 185일 뒤 47,000원 비교, 구매혜택도 더했어요.
  • 목업의 기능을 지금 사이트 코드 · DB · 공식 페이지와 하나씩 대조해 «실제로 만들 수 있나»에 정리했어요.
  • 대표님이 정해 주셔야 할 것 14가지는 맨 아래 «결정할 것»에 모았어요.

누구를 위한 사이트

목표는 한 줄이에요. 처음 온 손님이 3분 안에 «내 조건이면 한 달에 얼마»를 알고, 전화 없이 주문서까지 끝내는 것.

이런 손님이 와요

  • 휴대폰을 새로 사거나 바꾸려는 사람
  • 어디서 사야 안전한지 고민하는 사람
  • 매장이나 전화 없이 온라인으로 끝내고 싶은 사람
  • LG U+를 쓰거나 옮기려는 사람 중 공식 인증 대리점을 찾는 사람

시안이 하는 약속

«제품은 새로워도, 사는 건 복잡할 필요 없으니까.» 그래서 모든 화면은 세 가지를 지켜요.

  • 복잡한 조건은 덜어낸다 — 한 번에 하나만 묻기
  • 필요한 기준만 보여준다 — 실구매가와 월 납부 금액
  • 명확하게 말한다 — 쉬운 말, 조건 없음은 «없음»으로

화면별 설계

«가져옴»은 지금 사이트에서 그대로 옮긴 것, «새로»는 이번에 더한 것이에요. 화면마다 목업의 «기획 메모»에도 같은 내용이 있어요.

첫 화면

시안 그대로. 큰 그림 → 어떤 휴대폰을 찾으세요? → 하유 가이드 3글 → 아이폰 사전알림 띠 → 먼저 산 손님의 이야기.

  • 새로: 칩을 누르면 카드가 시리즈로 바뀜
  • 새로: 카드에 실제 상품 사진

휴대폰 목록

아이폰 · 갤럭시 탭 → «지금 LG U+ 쓰세요?» → 시리즈 제목별 상품 카드(실구매가 크게, 월 납부 작게).

  • 가져옴: 통신사 질문, 상품별 기본 요금제
  • 새로: 질문을 창 대신 화면 위에 두고 언제든 바꾸기

상품 화면

통신사 → 용량 · 색상 → 요금제 → 할인 방법 → 구매 방식 → 금액표 → 주문하기(모바일은 아래 고정).

  • 가져옴: 고르는 순서, 금액표 줄 이름, 조건 없음 4가지, 네 단계, 주문 안내, 자주 묻는 질문
  • 새로: 24개월 동안 덜 내는 할인 방법 알려주기
  • 새로: 요금제 창에서 요금제마다 월 납부 금액
  • 새로: 캔바 상세 그림이 붙는 자리 표시
  • 새로: 185일 뒤 47,000원으로 낮춘 경우 비교 · 24개월 합계 창
  • 새로: 색상은 동그라미 + 고른 색 이름(지금은 펼침 목록)

출시 전 상품

대표 사진 · 색상 → «가격 출시 후 안내» → 사전알림과 사전예약 차이 한 줄 → 알림 신청하기.

  • 가져옴: 출시 알림 상품 방식(용량 · 가격 숨김)

로그인 창 · 주문서

주문하기 → 카카오 · 네이버 로그인 → 주문서(가입하시는 분 · 받으실 곳 · 포인트 · 약관) → 주문 접수하기.

  • 가져옴: 로그인 필수, 칸 구성, 회원가입 1만 포인트
  • 새로: 로그인 정보로 이름 · 생년월일 · 휴대폰 미리 채움
  • 새로: 빠진 칸은 그 자리에 빨간 안내

접수 완료

«접수됐어요. 이제 신청서만 쓰면 끝이에요» → 진행 막대 → 지금 할 일 카드(온라인 신청서) → 주문 요약.

  • 가져옴: 문구, 진행 단계 이름(신청서 · 접수확인 · 준비·배송 · 개통완료)
  • 새로: 할 일을 검정 카드 하나로

회원가입

결정할 것

2026년 9월 16일 대표님 답을 각 항목 아래에 적었어요. 7번은 그 전에 답을 주셨어요.

  1. 첫 화면에 가격 한 줄

    시안에는 가격이 없어요. 카드에 «실구매가 OO원부터»를 넣을까요? 목업 «제안 보기»로 비교할 수 있어요.

    답: 안 넣어요. 종류를 보는 화면이라 가격이 필요 없어요(대표, 9/16).

  2. LG U+ 공식 인증 대리점 표시

    하이유플의 가장 큰 믿을 거리인데 시안에 없어요. 큰 그림 아래 믿음 띠로 둘까요?

    답: 푸터에 이미 마크가 있어 그것으로 갈음해요. 따로 믿음 띠는 안 만들어요(대표, 9/16).

  3. 개통 순서 안내 통일

    지금 사이트 안에서 서로 달라요. 상품 화면은 «개통 → 배송», 주문서 옆 안내는 «기기수령 및 개통». 번호이동과 기기변경에 따라 다르면 나눠 적어야 해요.

    답: 만들어진 화면을 보고 정해요. 글만 바꾸는 일이라 나중에 해도 돼요(대표, 9/16).

  4. 비상 연락처 필수 여부

    필수로 두면 왜 받는지 한 줄 설명을 달면 좋겠어요.

    답: 필수로 받아요. 본인 전화가 안 될 때와 미성년자 법정대리인 연락 때문이에요(대표, 9/16).

  5. 상품 이름 규칙

    띄어쓰기 · 영어 표기(PRO → 프로, AIR → 에어) · «사전예약»을 이름 대신 표시로. 정하면 자비스웹 상품 이름도 같이 바꿔요.

    답: 지금은 자비스웹 상품 이름 그대로 가요. 만들어진 화면을 보고 다시 정해요(대표, 9/16).

  6. «덜 내는 쪽 알려주기» 넣기

    할인 방법 두 개 중 24개월 동안 덜 내는 쪽을 알려주는 기능이에요. 실제 사이트에도 넣을까요?

    답: 넣어요. 다만 계산이 맞는지 한 번 더 검산해요(대표, 9/16).

  7. 마젠타 색 맞추기

    시안 #E5287E와 지금 사이트 #EB2894가 조금 달라요. 시안 값으로 맞출까요?

    답: 지금 사이트 색 #EB2894 로 가요(대표, 9/16).

  8. 회원가입 · 마이페이지 확인 3가지

    간편가입 뒤에 휴대폰 번호 같은 추가 정보를 받는지, 가입 포인트 1만이 «마일리지»로 들어가는지, «케이스 요청하기»를 언제부터 보여줄지.

    답: 마일리지는 이미 들어가요(가입 축하 적립 1만, 간편가입 포함 — 코드 확인). 케이스 요청하기는 상품 정보보기 쪽에 넣어요. 남은 것은 간편가입으로 들어와 번호가 빈 회원 처리 — 하이유플 실측 네이버 676명 중 205명, 카카오 1,491명 중 17명이 번호가 없어요(대표, 9/16).

  9. 구매후기 공개 방식과 감추는 기준

    손님이 올리면 바로 보여주고 나중에 감출까요(목업 방식), 직원이 본 뒤에 보여줄까요? 감추는 기준도 정해야 해요. 예) 얼굴 · 주소 · 전화번호 · 송장이 보이는 사진, 상관없는 사진, 욕설 · 광고 글.

    답: 직원이 본 뒤에 공개해요(대표, 9/16).

  10. 하유 가이드 글 공개 방식

    관리 화면은 자비스웹 «판매몰 관리 › 손님몰 화면»에 두는 것으로 확인했어요(손님 사이트에는 없음). 하유 가이드 글을 저장하면 바로 공개할지, 대표님 확인 뒤 공개할지.

    답: 저장하면 바로 공개해요. 단 저장 전에 미리보기를 볼 수 있어야 해요(대표, 9/16).

  11. 배너 글자 방식

    시안처럼 제목 · 설명 · 단추를 화면 글자로(배너 틀 1200:500 · 글자 칸 개발) 할지, 지금처럼 글자를 그림에 그려 넣을지.

    답: 화면 글자로 만들어요. 배너 그림은 배경만 쓰고 제목·설명·단추는 자비스웹 칸에 글로 넣어요(대표, 9/16).

  12. 인터넷 결합 금액 표시

    9월 15일 하이폰 · 하이스테이션 인터넷 화면에서는 «휴대폰 결합 요금» · «같이 하면 지원금» 표기를 뺐어요. 하이유플 «휴대폰 + 인터넷 같이» 공간에서는 LG U+ 공식 할인표와 계산기로 금액을 보여줄지, 표만 둘지.

    답: 금액을 보여줘요. 다만 결합 공간을 더 손본 뒤 미리보기를 보고 확정해요(대표, 9/16).

  13. 가입내역 확인 자동화

    지금처럼 직원이 카카오톡으로 보내고 답장을 받을지, 알림톡(신청내역 확인 링크)과 «내용이 맞아요» 단추로 바꿀지. 바꾸면 알림톡 문안 검수(영업일 2일)와 개발이 필요해요.

    답: 지금처럼 직원이 카카오톡으로 보내요. 「내용이 맞아요」 단추는 목업에서만 동작을 보여줘요(대표, 9/16).

  14. 지금 사이트 문제 고침 넘기기

    «배송대기» 단계 표시, 직원용 [배송조회] 우체국 고정, 접수 상세 송장이 출고 알림 목록에 안 잡힘 — hi-web-test 자리로 넘길지.

    답: 직원 화면 [배송조회]가 우체국으로 고정된 것을 고쳐요. 로젠 API 는 우리가 로젠과 직접 계약한 게 아니라 거래처를 통해 받는 구조여서 붙이기 어려워요. 송장번호를 복사해 네이버 통합 택배조회 화면에서 보게 하는 쪽으로 가요(대표, 9/16).
