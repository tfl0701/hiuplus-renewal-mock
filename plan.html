한눈에

  • 첫 화면은 시안 그대로 써요. 오타 세 곳만 고쳤어요(이어폰 → 아이폰 등).
  • 뒤에 붙는 화면 12개를 시안 모양으로 이어 만들었어요. 검정 머리, 둥근 회색 카드, 계절 색 라벤더, 신청 단추에만 마젠타.
  • 고르는 순서와 금액표 줄 이름은 지금 사이트 그대로 둬서 기존 손님이 헤매지 않게 했어요.
  • 새로 넣은 건 세 가지예요. 24개월 동안 덜 내는 할인 방법 알려주기, 요금제마다 월 납부 금액 같이 보여주기, 접수 뒤에 할 일을 단추 하나로 보여주기.
  • 대표님이 정해 주셔야 할 것 7가지는 맨 아래 «결정할 것»에 모았어요.

누구를 위한 사이트

목표는 한 줄이에요. 처음 온 손님이 3분 안에 «내 조건이면 한 달에 얼마»를 알고, 전화 없이 주문서까지 끝내는 것.

  • 매장이나 전화 없이 온라인으로 끝내고 싶은 사람
  • LG U+를 쓰거나 옮기려는 사람 중 공식 인증 대리점을 찾는 사람

시안이 하는 약속

«제품은 새로워도, 사는 건 복잡할 필요 없으니까.» 그래서 모든 화면은 세 가지를 지켜요.

  • 복잡한 조건은 덜어낸다 — 한 번에 하나만 묻기
  • 필요한 기준만 보여준다 — 실구매가와 월 납부 금액
  • 명확하게 말한다 — 쉬운 말, 조건 없음은 «없음»으로

화면별 설계

«가져옴»은 지금 사이트에서 그대로 옮긴 것, «새로»는 이번에 더한 것이에요. 화면마다 목업의 «기획 메모»에도 같은 내용이 있어요.

첫 화면

시안 그대로. 큰 그림 → 어떤 휴대폰을 찾으세요? → 알고사기 3글 → 아이폰 사전알림 띠 → 먼저 산 손님의 이야기.

  • 새로: 칩을 누르면 카드가 시리즈로 바뀜
  • 새로: 카드에 실제 상품 사진

휴대폰 목록

종류 칩 → «지금 LG U+ 쓰세요?» → 정렬 → 상품 카드(실구매가 크게, 월 납부 작게).

  • 가져옴: 통신사 질문, 상품별 기본 요금제
  • 새로: 질문을 창 대신 화면 위에 두고 언제든 바꾸기

상품 화면

통신사 → 용량 · 색상 → 요금제 → 할인 방법 → 구매 방식 → 금액표 → 주문하기(모바일은 아래 고정).

  • 가져옴: 고르는 순서, 금액표 줄 이름, 조건 없음 4가지, 네 단계, 주문 안내, 자주 묻는 질문
  • 새로: 24개월 동안 덜 내는 할인 방법 알려주기
  • 새로: 요금제 창에서 요금제마다 월 납부 금액
  • 새로: 캔바 상세 그림이 붙는 자리 표시

출시 전 상품

대표 사진 · 색상 → «가격 출시 후 안내» → 사전알림과 사전예약 차이 한 줄 → 알림 신청하기.

  • 가져옴: 출시 알림 상품 방식(용량 · 가격 숨김)

로그인 창 · 주문서

주문하기 → 카카오 · 네이버 로그인 → 주문서(가입하시는 분 · 받으실 곳 · 포인트 · 약관) → 주문 접수하기.

  • 가져옴: 로그인 필수, 칸 구성, 회원가입 1만 포인트
  • 새로: 로그인 정보로 이름 · 생년월일 · 휴대폰 미리 채움
  • 새로: 빠진 칸은 그 자리에 빨간 안내

접수 완료

«접수됐어요. 이제 신청서만 쓰면 끝이에요» → 진행 막대 → 지금 할 일 카드(온라인 신청서) → 주문 요약.

  • 가져옴: 문구, 진행 단계 이름(신청서 · 접수확인 · 준비·배송 · 개통완료)
  • 새로: 할 일을 검정 카드 하나로

내정보

로그인 전: 카카오 · 네이버. 로그인 후: 진행 중인 주문(단계 · 지금 할 일) · 알림 신청 내역 · 최근 본 휴대폰.

  • 새로: 개통 뒤 «요금제를 낮출 수 있을 때까지 185일»

알고사기

주제 칩 → 글 목록. 글은 «짧게 답하면» → 설명 → 실제 금액표 → «내 조건으로 보기».

  • 새로: 글 속 금액표가 실제 가격으로 계산됨
  • 새로: 6개 글 (구매 조건 · 요금제 · 사전알림 · 가입 방법 · 할인 방법 · 할부 이자)

구매후기

평균 별점 → 사진 후기 거르기 → 후기 카드 → 후기 한 편 → «나도 내 조건으로 보기».

  • 가져옴: 지금 후기 일부(이름 가림 그대로)
  • 제안: 후기 쓰기에 «어떤 휴대폰을 샀나요» 고르기

고객센터 · 상담 · 검색 · 전체 메뉴

결정할 것

대표님이 정해 주시면 그대로 실제 사이트 작업으로 넘길게요.

  1. 첫 화면에 가격 한 줄

    시안에는 가격이 없어요. 카드에 «실구매가 OO원부터»를 넣을까요? 목업 «제안 보기»로 비교할 수 있어요.

  2. LG U+ 공식 인증 대리점 표시

    하이유플의 가장 큰 믿을 거리인데 시안에 없어요. 큰 그림 아래 믿음 띠로 둘까요?

  3. 개통 순서 안내 통일

    지금 사이트 안에서 서로 달라요. 상품 화면은 «개통 → 배송», 주문서 옆 안내는 «기기수령 및 개통». 번호이동과 기기변경에 따라 다르면 나눠 적어야 해요.

  4. 비상 연락처 필수 여부

    필수로 두면 왜 받는지 한 줄 설명을 달면 좋겠어요.

  5. 상품 이름 규칙

    띄어쓰기 · 영어 표기(PRO → 프로, AIR → 에어) · «사전예약»을 이름 대신 표시로. 정하면 자비스웹 상품 이름도 같이 바꿔요.

  6. «덜 내는 쪽 알려주기» 넣기

    할인 방법 두 개 중 24개월 동안 덜 내는 쪽을 알려주는 기능이에요. 실제 사이트에도 넣을까요?

  7. 마젠타 색 맞추기

    시안 #E5287E와 지금 사이트 #EB2894가 조금 달라요. 시안 값으로 맞출까요?
